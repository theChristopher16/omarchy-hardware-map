# iPad mini 2 J85 RAM-boot storage inventory

This owner-run observation concerns one iPad mini 2 Wi-Fi (A1489/J85) on an
experimental runtime9 Linux RAM boot on 27 October 2026. The [draft bring-up
report](https://github.com/OrchardLinux/hardware/pull/5) records the broader
boot and hardware context.

A read-only Linux block-device inventory on the same RAM boot listed only
empty loop, network-block and zram devices. The root filesystem was rootfs;
no internal physical block device appeared in that inventory. No block
device was opened, no filesystem was mounted and no storage or bootloader
was written for this observation.

This means the running kernel did not expose a usable internal disk for an
installation at that moment. It does not prove the physical storage absent or
that another kernel could not support it. The [Hoolock A7 feature
matrix](https://github.com/HoolockLinux/docs/blob/master/features/A7.md)
lists internal storage as work in progress. A supported controller, device
verification and a recovery plan are needed before considering installation.
The existing external-root server was not restarted for this observation.

No recovered firmware, calibration, private logs, credentials, network
addresses or personal device identifiers are included here.

# Starter catalog

Paths use `component-type/manufacturer/component-model/report-id.json`. The entries are source-linked starting points, not an exhaustive or live catalog. “Unspecified” is intentional when the source was not reviewed for an exact manufacturer or component model. The website database is authoritative for approved community reports; use its JSON export and `scripts/catalog/export-tree.mjs` to create a current snapshot.
